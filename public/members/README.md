# Member assets

High-resolution portraits for each BTS member live in:

- `{id}/portrait-master.jpg` — master file
- `{id}/portrait.jpg` — store portrait
- `{id}/hero.jpg` — shop hero
- `{id}/shop-avatar.jpg` — cards / nav

See `manifest.json` for source notes.

Wikimedia original downloads were blocked in this build environment, so shop-ready
editorial portraits were generated and stored locally at high resolution.
